# JavaScript Functions - Reflection

### How did you approach creating more flexible functions with parameters?

I used parameters to make my functions reusable and accept different inputs. I also practiced using optional parameters with default values.

### 2. What challenges did you face while incorporating conditional logic in your functions?

The main challenge was validating user input and making sure the functions handled invalid or missing values correctly.

### 3. How does refactoring improve the readability and maintainability of your code?

Refactoring helps keep code clean, organized, and easier to understand. It also reduces unnecessary code and makes it easier to update or reuse functions in the future.
